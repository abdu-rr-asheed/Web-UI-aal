# Research data

**Only pseudonymised, non-identifiable aggregate data belongs here** (PRD §8.4, §13.6).

Never commit: participant names, contact details, recordings, or the
identity↔code linking file. Those live only on encrypted Kingston University
UK-tenant storage and are destroyed at the end of analysis.

This directory is `deny`-listed for reading in `.claude/settings.json` so
participant data cannot be pulled into an AI context window.
