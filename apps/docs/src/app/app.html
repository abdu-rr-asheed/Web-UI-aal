Navigation

Open the Components submenu in the header and press Escape — it closes and focus returns to the trigger you opened it from. Below the tab list, ← and → move focus without switching panel; Enter commits. That is manual activation (ADR-0008).

Site navigation is a list of links, so it keeps native list and link semantics. Marking it up as role="menu" would switch a screen reader into application mode and remove the site's own navigation from "list all links".

A menu of actions, where role="menu" genuinely is correct:
